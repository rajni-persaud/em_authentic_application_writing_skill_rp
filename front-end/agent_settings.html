Agent settings

Choose which model powers the coach and customize its writing instructions. These settings are shared by chats in this local app.

Model provider

The key is held in backend memory until the backend stops. It is not written to the settings file.

OpenAI requires an API key and may charge for usage. To use it across restarts, set OPENAI_API_KEY before starting the backend.

Model names are entered as provided by the selected service. For Ollama, download the model first with ollama pull model-name.

Writing prompts

Built-in prompt files stay unchanged. Customized versions are saved in this computer's local app settings.
